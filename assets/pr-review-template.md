# PR 审查评论模板

> 使用此模板生成 PR 审查评论。根据发现的严重度选择对应模板。

---

## 模板 A：有发现的问题

> 当发现任何需要修复的问题时使用此模板。

```
## 🔍 代码审查结果

共发现 **{N}** 个阻塞问题、**{M}** 个重要问题、**{K}** 个建议。

---

### 🔴 阻塞问题（必须修复后才能合并）

#### 1. {问题简述}
**位置：** `{文件路径}:{行号}`
**专家组：** {专家名}
**问题：**
{问题描述，1-2 句话}

**当前代码：**
```{语言}
{问题代码片段}
```

**修复建议：**
```{语言}
{修复后的代码示例}
```

**原因：** {为什么这是阻塞级的解释}

---

（重复每个阻塞问题）

---

### 🟠 重要问题（强烈建议修复）

#### 1. {问题简述}
**位置：** `{文件路径}:{行号}`
**专家组：** {专家名}

**问题：**
{问题描述}

**修复建议：**
{建议}

---

（重复每个重要问题）

---

### 🟡 建议（可选优化）

#### 1. {建议简述}
**位置：** `{文件路径}:{行号}`

{建议内容}

---

### 📊 量化指标

| 指标 | 值 | 是否达标 |
|-----|-----|----------|
| P0 问题数 | {N} | {✅/❌} |
| P1 问题数 | {M} | {✅/❌} |
| P2 问题数 | {K} | ✅ |

---

### 结论

- [ ] ✅ 通过，可合并
- [ ] ⚠️ 修复 P0 后合并
- [ ] ❌ 不通过，需重写

{N 若 > 0，结论应为 ❌ 或 ⚠️}
```

---

## 模板 B：无问题

> 当未发现任何阻塞或重要问题时使用。

```
## ✅ 代码审查结果

审查完成，未发现阻塞或重要问题。

### 统计
- 文件审查：{N} 个
- 阻塞问题：0
- 重要问题：0
- 建议：{K} 个

{N 若 > 0，列出建议}

### 结论
✅ 通过，可合并
```

---

## 模板 C：仅建议

> 当只有改进建议，无阻塞/重要问题时使用。

```
## 🔍 代码审查结果

发现 {K} 个改进建议，无阻塞问题。

### 💡 改进建议

#### 1. {建议简述}
**位置：** `{文件路径}:{行号}`
**建议：** {建议内容}

---

### 结论
✅ 通过，建议修复后合并
```
