# 安全漏洞检查清单

## SQL 注入

| 检查点 | 说明 |
|-------|------|
| 参数化查询 | 是否使用 PreparedStatement / ORM 参数绑定？ |
| 字符串拼接 SQL | 是否存在 `${}` 拼接（MyBatis）？ |
| 动态表名/列名 | 是否白名单校验？ |
| ORDER BY 注入 | 是否校验排序字段？ |

## XSS（跨站脚本）

| 检查点 | 说明 |
|-------|------|
| 输入输出编码 | 是否对用户输入做 HTML 转义？ |
| 富文本过滤 | 是否使用白名单 HTML 过滤器？ |
| CSP 策略 | 是否配置 Content-Security-Policy？ |
| URL 跳转 | 是否校验 redirect URL 白名单？ |

## CSRF（跨站请求伪造）

| 检查点 | 说明 |
|-------|------|
| CSRF Token | 状态变更操作是否校验 Token？ |
| SameSite Cookie | 是否设置 SameSite 属性？ |
| Referer 校验 | 是否校验请求来源？ |

## 敏感数据

| 检查点 | 说明 |
|-------|------|
| 日志脱敏 | 手机号、身份证、银行卡号是否脱敏？ |
| 返回值脱敏 | 接口返回是否过滤敏感字段？ |
| 传输加密 | 是否使用 HTTPS？敏感参数是否加密？ |
| 存储加密 | 密码是否加盐哈希？密钥是否安全存储？ |

## 权限控制

| 检查点 | 说明 |
|-------|------|
| 认证校验 | 接口是否校验登录状态？ |
| 授权校验 | 是否校验操作权限？ |
| 水平越权 | 是否校验数据归属（能操作别人的数据吗）？ |
| 垂直越权 | 普通用户能否访问管理接口？ |
| IDOR | 是否通过遍历 ID 访问未授权资源？ |

## 邮件/模板注入

| 检查点 | 说明 |
|-------|------|
| HTML 转义 | 用户输入拼入邮件/模板前是否 `html.escape()`？ |
| 富文本过滤 | 邮件正文是否允许用户控制 HTML 结构？ |
| URL 拼接 | 用户提交的 URL 直接作为 `<a href>` 是否校验协议（javascript:）？ |

## 其他安全项

| 检查点 | 说明 |
|-------|------|
| 文件上传 | 是否校验文件类型、大小？是否可执行？ |
| 命令注入 | 是否拼接用户输入到系统命令？ |
| SSRF | 是否校验外部请求 URL？ |
| 反序列化 | 是否反序列化不可信数据？ |
| 弱密钥检测 | 密钥是否包含可推测模式（项目名、年份、"change-me"等）？ |
